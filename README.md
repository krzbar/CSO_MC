# CSO_MC

These are the R scripts and numerical results accompanying 
Krzysztof Bartoszek
Cubic stochastic operators for Markov chains and mappings of distributions

The script CSO_3D_Fig1.R is for Fig. 1. To recreate it the user should in R run
set.seed(1)
source("CSO_3D_Fig1.R")
fplotlimitstraj()

Figures 3-14 are created using the scripts CSO_4D_basins.R, CSO_4D_basins_run_batch.R, CSO_4D_systems.R.
These three scripts were generated by Claude Fable 5.1, except for the systems present in CSO_4D_systems.R.
These were manually entered. To recreate the graphics (both pdfs and pngs) for Figs. 3-14, one should call
in the command line:

Rscript CSO_4D_basins_run_batch.R CSO_4D_systems.R
